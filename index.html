How Shuffle Works ships

Small tools with enough Spark context to be useful when a job is already slow, surprising, or expensive.

  • Local-first Keep event logs and schemas in the browser or local workflow instead of sending cluster evidence to a backend.
  • Runtime evidence Start from the artifacts Spark already emits: history logs, DataFrame schemas, stages, memory pressure, and shuffle reads.
  • Spark internals Explain the tuning levers that actually matter: AQE, partitioning, serialization, executor memory, and skew.
