Built around Spark evidence

Small tools for a job that's slow, surprising, schema-fragile, or expensive, built around the evidence Spark leaves behind.

  • No upload path Keep event logs and schemas in the browser or local workflow instead of sending cluster evidence to a backend.
  • Event log first Start from the artifacts Spark already emits: history logs, DataFrame schemas, stages, memory pressure, and shuffle reads.
  • Spark setting, not superstition Explain the tuning levers that actually matter: AQE, partitioning, serialization, executor memory, and skew.
