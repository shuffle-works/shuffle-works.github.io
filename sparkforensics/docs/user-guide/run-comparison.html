Run comparison mode ​

Put two runs side by side to see whether a tuning change helped.

Starting a comparison ​

From the landing page, click Compare two runs. Two slots appear, Run A and Run B.

  1. Load a file into each slot the same way you'd load a single run (drag and drop, or Choose file).
  2. Click Compare.

The runs parse one after the other through the same background worker. When both finish, the comparison view opens.

Reading the comparison ​

The comparison page shows what changed between the two runs: findings that appeared or disappeared, plus metric deltas for duration, spill, GC time and so on.

For either run's full dashboard, click View run A dashboard or View run B dashboard. ← Back to comparison takes you back.
