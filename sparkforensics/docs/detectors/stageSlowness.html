SLOW

Slow stage

A stage runs for a long stretch of the job with no single cause flagged on it.

Outcome

An example finding

A synthetic example. A small event log built to fire this detector at its default thresholds, stage-slowness.ndjson (Spark 3.5.3), read by the real analyzer. It is not a real production run.

This stage ran 17.3 minutes with no more specific cause flagged and reads mostly input files: often too few or too uneven input partitions, so check input file sizes and lower spark.sql.files.maxPartitionBytes, or look for a large per-task data volume driving heavy spill.

CI (CLI)

List this entry from the command line. The output below is a real run of the command. Budgets and exit codes are in the CI guide. 

sparkforensics-analyze detectors --type stageSlowness --format md
# Detectors (1)

## Speed

| Tag | Type | Scope | Fix | Gate | What it finds |
| --- | --- | --- | --- | --- | --- |
| SLOW | `stageSlowness` | stage | code |  | A stage runs for a long stretch of the job with no single cause flagged on it. |

Report only this finding type for a run with --type:

sparkforensics-analyze <event-log> --type stageSlowness --impact critical,warning,info

It has no budget flag. Fail a build on a new one by comparing against a baseline with --fail-on-introduced.

Airflow

The operator has no budget parameter for it. Use fail_on_introduced with a baseline.

check_spark_job = SparkForensicsOperator(
    task_id="check_spark_job",
    log_source=...,
    backend=SubprocessAnalyzeHook(),
    baseline_log_source=...,
    fail_on_introduced="critical",
)

The operator works per run, and its summary counts findings per impact band. See the operator for its parameters.

How it is measured

Thresholds

A stage running far longer than its peers, not attributable to a single slow host.

stageSlowness version 2

ThresholdDefault
infoMin15

Suppressed by slowHost: this detector drops its finding on any stage slowHost flagged in the same run.

Each rule's impact bands and fixed fallbacks are in the threshold tables.

Override a default per run with --thresholds; see Tuning detector thresholds.
